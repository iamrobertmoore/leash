For sellers

One read before you serve an agent.

Any API, site or contract can ask Monad whose agent this is, what it may still spend today, and whether this payment will go through. No API key, no Leash server in the path, no trust in the agent's own word.

Try it: curl -i https://leash-monad.vercel.app/api/forecast answers 402 until an agent pays inside its leash.

// npm i leash-monad viem
import { checkAgent, leashGate } from "leash-monad";

// one read, before any work
const v = await checkAgent(agent, me, "2.00");
// { status: "OVER_CAP", remainingToday: "0.0", erc8004Id: "10281", ... }

// or the whole x402-style flow as middleware
const g = await leashGate(req, { seller: me, priceUsd: "1" });
if (!g.allow) return res.status(g.status).json(g.body); // 402 / 403
