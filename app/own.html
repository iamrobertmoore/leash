Leash your own agent

Give your agent a budget it can't break.

Any agent with a key: an MCP server in Claude or Cursor, a script, a bot. Your passkey sets what it may spend each day and who it may pay. Monad checks it inside every payment, so a hijacked or confused agent can't spend past it.

Run this once. It prints an agent address and its key. Or use any Monad address your agent already controls.
